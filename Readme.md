# rev-report

rev-report is a rust application that produces business intelligence from raw csv data on projects and revenue forecasts.

[![blazingly fast](https://blazingly.fast/api/badge.svg?repo=psodm%2Frev-report)](https://blazingly.fast/hall-of-speed)

## Installation

TBF

```cargo
cargo build
```

## Usage

```cargo
cargo run
```
